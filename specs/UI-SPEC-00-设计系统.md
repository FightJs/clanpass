# UI-SPEC-00 · 设计系统

> 状态：Draft · 对应功能 SPEC-01～05 · 仅设计规格，不写代码  
> 视觉方向（已拍板）：**「工头 · 夜间工棚」** — 深色工具仪表盘 + 金色倒计时强调  
> 风格锚点：ClashClock / clash.ninja 的游戏伴随工具感 × Linear / Things 的排版纪律  
> 不走：赛博 RGB 风、拟物游戏 UI 克隆、浅色默认（可后置暗色以外主题）

---

## 1. 设计原则

| 原则 | 含义 | 落地 |
|---|---|---|
| **时间第一** | 打开就看剩余时间，不是先看品牌 | 倒计时数字是全站最大字号 |
| **一屏一事** | 每屏一个主任务，避免信息过载 | 卡片分区 + 大留白 |
| **诚实数据** | 快照会旧、Boost 会偏，界面必须说明 | 状态条、角标、脚注 |
| **安静提醒** | 通知有用，但不吵 | 弱强调色、免打扰默认克制 |
| **中文优先** | 文案短句、口语，不用翻译腔 | 字体按中文屏优化 |

## 2. 色彩 Color

| Token | Hex | 用途 |
|---|---|---|
| `--ink` | `#E8ECF4` | 主文字 |
| `--ink-2` | `#A8B2C4` | 次级文字 |
| `--ink-3` | `#6B7589` | 弱提示 / 占位 |
| `--gold` | `#F0B429` | **主强调**：倒计时、主按钮、进行中 |
| `--gold-weak` | `rgba(240,180,41,0.14)` | 金色底、进度轨道高亮 |
| `--lab` | `#8B7CF6` | 实验室研究（区分建筑工） |

| `--event-weak` | `rgba(76,154,255,0.14)` | 事件卡底 |
| `--ok` | `#3DDC97` | 已完成、成功 |
| `--warn` | `#F5A524` | 将完成、数据陈旧 |
| `--danger` | `#F07178` | 错误、清除数据、权限被拒 |

### 2.2 表面与线

| Token | Hex / 值 | 用途 |
|---|---|---|
| `--bg` | `#0C1017` | App 背景 |
| `--bg-2` | `#121826` | 次级面（Tab 区、列表底） |
| `--card` | `#1A2233` | 卡片 |
| `--card-2` | `#222C40` | 卡片内嵌/输入区 |
| `--line` | `rgba(232,236,244,0.08)` | 分割线 |
| `--line-strong` | `rgba(232,236,244,0.14)` | 描边、输入边框 |
| `--overlay` | `rgba(6,8,12,0.72)` | 模态遮罩 |
| `--focus` | `#F0B429` | 焦点环 |

### 2.3 状态色语义

| 状态 | 色 | 使用处 |
|---|---|---|
| 进行中 · 建筑工 | `--gold` | 建筑卡、lane 图标 |
| 进行中 · 实验室 | `--lab` | 实验室卡 |
| 即将完成（≤5min） | `--warn` | 倒计时数字描边/进度条 |
| 已完成 | `--ok` | 徽章，卡片降透明 |
| 数据陈旧 | `--warn` | 状态条、导入提示 |
| 空闲 / 空态 | `--ink-3` | 空态插画线稿 |
| 禁用 | `--ink-3` + 40% 透明 | 关闭的开关 |

### 2.4 对比度要求

- 正文 `--ink` on `--card` ≥ 4.5:1
- 大号倒计时数字 ≥ 3:1（非正文场景）
- 不用纯红/纯绿作为唯一状态信号（配图标/文案）

### 2.5 主题

| 主题 | 阶段 | 说明 |
|---|---|---|
| **Dark（默认）** | MVP | 上表全量 |
| Light | P2 | 背景改暖白 `#F7F3EC`，ink 反转，金强调保持 |
| 跟随系统 | P2 | `prefers-color-scheme` |

## 3. 字体 Typography

### 3.1 字族

```css
--font-sans: "PingFang SC", "SF Pro Text", "HarmonyOS Sans SC",
             "Noto Sans SC", "Microsoft YaHei", system-ui, sans-serif;
--font-num: "SF Mono", "JetBrains Mono", "Roboto Mono",
             ui-monospace, monospace; /* 倒计时等宽数字 */
```

- 中文 UI 一律 `--font-sans`
- **倒计时、时间戳、编号**用 `--font-num` + `font-variant-numeric: tabular-nums`

### 3.2 字阶（移动优先）

| Token | Size / Line | Weight | 用途 |
|---|---|---|---|
| `display-time` | 36 / 1.1 | 600 | 卡片剩余时间（如 `2天 03:15`） |
| `display-n` | 28 / 1.15 | 600 | 首页总览数字 |
| `title` | 20 / 1.3 | 600 | 页面标题 |
| `title-sm` | 17 / 1.35 | 600 | 卡片标题 |
| `body` | 15 / 1.55 | 400 | 正文 |
| `body-strong` | 15 / 1.55 | 600 | 列表主信息 |
| `caption` | 13 / 1.4 | 400 | 辅助说明 |
| `overline` | 11 / 1.2 | 600 | 分区标签（宽字距） |
| `tab` | 11 / 1.2 | 500 | 底栏文字 |

### 3.3 排版规则

- 中文标点不用折行挤压；标题最多 2 行
- 倒计时永不换行；空间不够先缩「秒」再缩「天」文案
- 等宽数字避免每秒抖动（宽度固定）
- 字重对比：信息层级靠 **字号 + 字重 + 颜色** 三者至少两项

## 4. 布局 Layout

### 4.1 画布

| 断点 | 宽 | 处理 |
|---|---|---|
| 手机（主） | 360–430 | 默认流式单列 |
| 大手机/分屏 | 431–560 | 同单列，内容 max-width 480 居中 |
| 平板/桌面 | ≥561 | 内容列 560 居中；侧栏预留（P2） |

安全区：`env(safe-area-inset-*)`；底栏高度 + 安全区。

### 4.2 间距 Spacing

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40`

| 场景 | 值 |
|---|---|
| 页面左右 gutter | 16 |
| 卡片内边距 | 16 |
| 卡片纵向间距 | 12 |
| 分区间距 | 24 |
| 底栏高 | 56 + safe-area |
| 顶栏高 | 48 |

### 4.3 圆角 Radius

| Token | 值 | 用途 |
|---|---|---|
| `r-sm` | 8 | 按钮、chip、输入 |
| `r-md` | 12 | 卡片 |
| `r-lg` | 16 | 大卡、面板、弹层 |
| `r-pill` | 999 | 徽章、分段控件 |

### 4.4 阴影 / 海拔

深色系少用阴影，靠表面色阶 + 1px 描边：

| 层级 | 样式 |
|---|---|
| 卡片 | `border: 1px solid --line`，无阴影 |
| 浮起（底栏、弹层） | `0 -8px 32px rgba(0,0,0,0.45)` |
| 弹窗 | `0 16px 48px rgba(0,0,0,0.55)` |

## 5. 图标与插画

| 项 | 规范 |
|---|---|
| 图标风格 | 线性 24px grid，1.75 stroke，圆角端点 |
| 底栏图标 | 22px，激活填充金/紫，未激活 `--ink-3` |
| 不使用 | 像素风、拟物锤子/圣水瓶抄袭游戏图标 |
| 空态插画 | 单色线稿（`--ink-3`）+ 一个金色点缀 |
| 成就/庆祝 | 克制；仅轻动画 + `--ok` |

## 6. 动效 Motion

| 场景 | 时长 / 缓动 | 规范 |
|---|---|---|
| 页面切换 | 160ms ease-out | 淡入 + 4px 上移，无横向飞入 |
| 卡片展开 | 200ms | 高度展开，不旋转 |
| 倒计时数字 | — | **不做**每秒数字滚动动画 |
| 进度条 | 400ms ease | 仅在数值变化时 |
| Toast | 进 200ms / 出 160ms | 底部，自动消失 2.5s |
| 将完成呼吸 | 2s loop | 仅进度条微光，**禁止全屏闪烁** |

`prefers-reduced-motion: reduce` 时全部退化为透明度切换。

## 8. 文案语调（界面文案）

| 是 | 否 |
|---|---|
| 「还有 2 天 3 小时」 | 「T-48:00:00 remaining」 |
| 「重新粘贴一次就好」 | 「请执行数据同步操作」 |
| 「加速可能让游戏里更早完成」 | 「Boost simulation inaccurate」 |
| 「数据更新于 2 小时前」 | 「Last sync timestamp」 |

- 按钮：动词开头（粘贴并导入 / 知道了 / 去开启）
- 错误：先说发生了什么，再说怎么办
- 合规页脚短句：「非官方粉丝工具 · 数据仅存本机」

## 9. 可访问性

| 项 | 要求 |
|---|---|
| 点击目标 | ≥ 44×44 |
| 焦点 | 可见焦点环 `--focus` |
| 动态字号 | 正文可跟随系统至 120% 不裁切 |
| 读屏 | 倒计时 `aria-live="polite"`，频率≥30s 或完成时 |
| 色觉 | 状态 = 颜色 + 文案/图标 |
